# PostgreSQL 报告存储与历史保留

用户要求移除自动删除、推送新代码，并在 Mac Studio 创建数据表；已选择 PostgreSQL。

保留现有立即查询、IST 每小时 `:00/:20/:40`、进程锁和退出行为，移除 retention 模块、回调与跨日清理。历史报告由用户管理。

使用四张表保存报告批次、渠道快照、订单和账户；以批次和渠道隔离重复订单号。金额使用无固定精度的 NUMERIC，时间使用 TIMESTAMPTZ，原始摘要和翻页元数据以 JSONB 保留。可信汇总视图仅统计成功且完整的渠道。未知渠道不填零。

离线导出脚本复用现有报告校验和脱敏逻辑，以规范化报告摘要生成确定性批次 UUID。SQL 事务与 ON CONFLICT DO NOTHING 保证同报告重复导入不增加行，修改后的报告生成新批次。只生成建表和数据文件，由用户在 Mac Studio 用 psql 导入。

实际订单、账户和生成的数据 SQL 留在本地忽略目录；Git 只包含代码、表结构、测试和说明。验证涵盖历史报告跨日保留、精确金额、重复导入、外键、特殊字符及不完整渠道汇总隔离。
